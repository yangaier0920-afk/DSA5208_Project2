# Historical project records

This archive retains A-stage planning, contracts, audit results and release documentation. These records describe the stage at their original date: statements that B/C modelling had not started are historical, not the current project status. Active completed results and run instructions are in the project README and submission/Final_Report_EN.md.

Human-readable documentation and code were translated into English on 2026-10-12. Original non-data release bytes and their checksum manifest are retained in submission/reproduction/frozen_release_metadata.zip. Historical hashes refer to that immutable original snapshot, not to translated documentation. Data values, model parameters and scores have not been changed by translation.
