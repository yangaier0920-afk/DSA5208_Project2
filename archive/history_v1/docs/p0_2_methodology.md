# P0-2 full raw-data audit methodology

Audit all eight annual CSV exports using Spark, without editing the raw files. Preserve source filenames, file SHA-256, original line/text fields and code/configuration signatures. Check parsing, expected 12 fields, timestamps, station keys, rainfall finiteness/nonnegativity, units/types, duplicates, conflicting values and exact decimal precision. Reconcile annual Spark row counts with physical input inventory and require normal Java shutdown.

Time diagnostics retain original event timestamps and epoch remainder modulo 300. Examine per-station ordered cadence, short/nonmultiple intervals, daily phase changes and cross-year gaps. Candidate floor slots are diagnostic only; audit does not silently align timestamps or deduplicate collisions. Supplemental 2017 alignment diagnostics test +1 second for remainder 299 and enumerate affected keys, rain/metadata conflicts and date changes before a cleaning rule is confirmed.

Station-month coverage denominator is the complete calendar month, not the range between first and last records. Include zero-observation months for stations present that year. Distinguish station starts/stops from missed readings. Export common-station panels at alternative coverage cutoffs, complete-calendar daily network counts and metadata combination histories. Do not infer physical relocation from coordinate changes or use the latest name/coordinate for all history.

Update timestamp minus event time is an audit difference, not proof of first online availability. Preserve delayed but valid rainfall. Inspect extremes and decimal values without deleting them merely because they are not multiples of 0.2 mm. Missing dates are unknown rain, not zero.

Entry points: src/01_audit_raw.py with scripts/run_spark.py and spark_session.py; use --help for configured annual input and fresh evidence paths. Run synthetic anomaly tests, annual reconciliation, merged quality checks and report summaries. Preserve input bytes and output receipts. B/C machine acceptance was deferred at this stage; the audit created neither cleaned observations nor labels/models.

Evidence: annual_quality.csv, summary.json, station_month_coverage.csv, station_summary.csv, station_full_period_summary.csv, common_station_month_network_coverage.csv, daily_network_record_counts.csv, station_metadata_history.csv, timestamp_offsets.csv, daily_timestamp_offsets.csv, cadence_gap_counts.csv, year_boundary_gaps.csv, units_types.csv, update_delay_buckets.csv and anomaly/duplicate/gap/extreme examples. Each annual audit.json contains ten reconciliation checks; run_status.json records lifecycle and signatures. Use new output paths rather than overwriting original provenance.
