# Shared environment/interface sample

The fixture contains the first 2,000 records from each annual 2017–2024 export: 16,000 total and 473 station/year groups. It preserves the original schema and has recorded SHA-256 and worker identity. It is deliberately small and nonrandom, for Spark setup and interface checks, not training or weather conclusions. No full raw dataset is needed for this smoke test.

Install Python 3.11, Java 17 and requirements-spark.txt. Windows uses .venv\Scripts\python.exe and the Java/Hadoop setup helpers; macOS uses .venv/bin/python, JAVA_HOME for Java 17 and the project root as working directory. Run the shared-sample script shown in README_A_P1_6.md or consult the reader's --help. Validate row counts, columns, types and station/year summaries. Save each member's own receipt with normal Java shutdown; A's PASS does not imply B/C passed. The macOS branch existed but had not been tested at the historical 8 October stage. Later Mac checks have separate evidence.
