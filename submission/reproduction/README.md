# Original release checksum snapshot

frozen_release_metadata.zip is immutable historical provenance: it contains the original non-full-data release files and original release_manifest.json needed to reproduce their exact byte hashes. It deliberately preserves original bytes, including original-language historical text. It is not the active project documentation. All visible working documents, source comments/messages, notebooks and regenerated reports are English.

prepare_frozen_runtime.py restores this ZIP under hidden .runtime/frozen_root and links separately downloaded formal Parquet. It verifies original checksums without weakening guards. Current translated files are identified by the English documentation revision/translation inventory. Data values, model parameters and experimental metrics were unchanged. Original machine-path strings in visible receipts are translated display labels, not executable current paths; originals are in this snapshot/backups.
